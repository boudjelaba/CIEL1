# Grille d’évaluation – Mini-projet NAO

**BTS CIEL – Informatique et Réseaux (IR)**

**Objectif :** concevoir, programmer, tester et valider un scénario mettant en œuvre le robot NAO, en simulation puis sur le robot réel.

La note finale est calculée sur **20 points**, répartis entre trois parties.

| Partie | Critères d’évaluation | Points max. |
| --- | --- | --- |
| **A – Simulation Virtual Robot** | Trajectoire définie et validée par le professeur | 1,0 |
|  | Programme structuré et enchaînement des déplacements | 1,5 |
|  | Respect de l’itinéraire prévu | 2,0 |
|  | Tests, débogage et correction des erreurs | 1,5 |
|  | **Sous-total A** | **6,0** |
| **B – Scénario sur le robot réel** | Déclenchement d’une action à partir d’un mot-clé vocal | 2,0 |
|  | Apprentissage et reconnaissance d’un visage | 2,0 |
|  | Déclenchement de l’action attendue après reconnaissance | 1,5 |
|  | Utilisation pertinente des NAO Marks | 1,5 |
|  | Utilisation des commandes tactiles et vocales | 2,0 |
|  | Cohérence et enchaînement du scénario | 1,0 |
|  | **Sous-total B** | **10,0** |
| **C – Développement et validation** | Organisation et lisibilité du programme | 1,0 |
|  | Tests et prise en compte des erreurs | 1,0 |
|  | Explication des choix techniques et du fonctionnement | 1,0 |
|  | Autonomie, rigueur et sécurité lors des essais | 1,0 |
|  | **Sous-total C** | **4,0** |
| **Bilan final** | **NOTE FINALE** | **20,0** |

## Niveaux de maîtrise

| Niveau | Signification | Taux indicatif |
| --- | --- | --- |
| **NA** | Non acquis : réalisation non effectuée ou compétence non démontrée | 0 % |
| **EA** | En cours d’acquisition : réalisation partielle, compétence non stabilisée | 33,3 % |
| **A** | Acquis : réalisation satisfaisante, quelques améliorations possibles | 66,6 % |
| **TB** | Très bien maîtrisé : réalisation très satisfaisante, compétence transférable | 100 % |

## Conseils pour réussir

- Tester régulièrement le programme et corriger les erreurs rencontrées.
- Vérifier le bon fonctionnement en simulation avant les essais sur le robot réel.
- Assurer la cohérence et le bon enchaînement des actions.
- Être capable d’expliquer ses choix techniques et le fonctionnement du programme.
- Respecter les consignes de sécurité pendant les manipulations.

**À retenir :** la note évalue le fonctionnement du scénario, la qualité du programme, la validation par les tests et la capacité à expliquer les choix réalisés.
